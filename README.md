# Third Person Crosshair

Client-side Fabric mod for Minecraft 1.21.10.

Mouse button 5 toggles a rear third-person view with the player's head hidden and the crosshair visible.

## Requirements

- Minecraft 1.21.10
- Fabric Loader >= 0.19.5
- Fabric API
- Java 21+

## Build

```
./gradlew build
```

The jar ends up in `build/libs/`.
